# Editing Mode Hotkey
A simple plugin which adds a command and a hotkey to toggle the editing mode between "Source" and "Live Preview".
This command both toggles the default option, and changes the mode of all open editors.

## Installation
Install the plugin from the Obsidian community plugins browser, and enable it.

## Usage
Use the command `Toggle default editing mode (Source/Live Preview)` from the command palette, or press the default hotkey `Cmd/Ctrl` + `Shift` + `E` (this can be changed in the hotkey settings).

The command switches the default editing mode between Source and Live Preview and updates all open editors that are currently using the source editor mode.
